# Attribution and provenance

This project is a **new, independently written extension** motivated by:

- **Original code/project**: Mattia Fabiani, [One-Shot Near-Field Localization with AI-Optimized Hybrid Beamformer Design](https://github.com/mattiafabiani/One-Shot-Near-Field-Localization-with-AI-Optimized-Hybrid-Beamformer-Design) (MIT License; copyright © 2025 Mattia Fabiani).
- **Research article**: M. Fabiani, D. Dardari, A. A. D'Amico, and L. Sanguinetti, "One-Shot Near-Field Localization with AI-Optimized Hybrid Beamformer Design," IEEE ICC 2025, pp. 2509–2513. DOI: [10.1109/ICC52391.2025.11161317](https://doi.org/10.1109/ICC52391.2025.11161317).

The full original research implementation is **not** included here; the software is an independent, more compact implementation of a near-field localization testbed with newly added post-combiner low-bit ADC simulation, low-SNR experiments, a phase-only sub-connected analog array model, paired-SNR/position-safe data splitting, and diagnostic plots.

**Do not represent this project as an original discovery of near-field localization, as the upstream author's code, as a verified reproduction of the ICC 2025 paper results, or as a peer-reviewed publication.** New empirical results must be verified by executing the experiments. No guarantee that low-bit quantization improves performance is implied.

The original repository's MIT permission/copyright notice should remain attached to any files copied from that repository. The `LICENSE` in this repository also retains credit for the upstream author, though this compact implementation contains independently written source code.
